# 라운드서클 2026 할로윈 파티 — 깃허브 업로드 안내

현재 온라인 게임의 마지막 게시본인 **4번 버전**을 깃허브 페이지스에 올릴 수 있도록 준비한 파일 묶음입니다. 게임 내용은 마지막 게시본과 동일합니다. 이 파일 묶음을 준비한 것만으로 깃허브에 게시되지는 않습니다.

## 먼저 준비할 것

- 재원님의 깃허브 계정으로 로그인합니다.
- 기존 게임 저장소 `Roundcircle-Ghost-Hunting`은 그대로 두고 새 저장소를 만듭니다.
- 새 저장소 이름 제안: `Roundcircle-2026-Halloween-Party`
- 설치 프로그램이나 별도 빌드 작업은 필요하지 않습니다. 게임 코드, 로고, 배경, 스타일, 3D 라이브러리가 `index.html`에 포함되어 있습니다.

## 1. 새 저장소 만들기

1. 깃허브의 새 저장소 만들기 화면을 엽니다.
2. 소유자는 기존 게임 계정인 `roundcirclered0` 또는 실제로 게임을 관리할 본인 계정을 선택합니다.
3. 저장소 이름에 `Roundcircle-2026-Halloween-Party`를 입력합니다.
4. 공개 범위는 공개로 선택합니다. 깃허브 무료 요금제의 페이지스는 공개 저장소에서 사용할 수 있습니다.
5. 안내 파일 추가를 켠 뒤 저장소를 만듭니다. 처음 만들어진 안내 파일은 아래 업로드 과정에서 이 묶음의 안내 파일로 교체해도 됩니다.

공식 설명: [깃허브 페이지스 사이트 만들기](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## 2. 압축을 풀고 파일 올리기

1. `Roundcircle-2026-Halloween-Party-GitHub-v4.zip`의 압축을 풉니다.
2. 새 저장소의 **파일 추가 → 파일 업로드** 메뉴를 선택합니다.
3. 압축에서 나온 `index.html`, `README.md`, `THREE-LICENSE.txt`와 정적 게시 설정 파일을 저장소 맨 위에 올립니다.
4. 변경 내용을 저장해 기본 브랜치 `main`에 반영합니다. 변경 제안으로 저장했다면 제안을 병합해 `main`에 반영합니다.

**압축 파일 자체를 올리지 마세요.** 압축을 풀어 나온 파일을 올려야 합니다. 저장소의 첫 화면에서 `index.html`이 바로 보여야 하며, 별도 하위 폴더 안에만 있으면 안 됩니다. 파일 이름은 소문자 `index.html`로 유지하고 `index.html.txt`가 되지 않게 확인합니다.

휴대폰에서 압축 해제가 번거로우면 별도로 제공한 `index.html` 한 개만 새 저장소 맨 위에 올려도 게임이 동작하도록 구성했습니다. 필수 라이브러리의 저작권 고지도 해당 파일 안에 포함되어 있습니다.

공식 설명: [저장소에 파일 올리기](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## 3. 게임 주소 공개하기

저장소의 **설정 → 페이지스** 화면에서 아래와 같이 선택하고 저장합니다. 화면이 영문인 경우를 위해 실제 메뉴 표기를 함께 적었습니다.

| 항목 | 선택할 값 |
| --- | --- |
| 설정 화면 | `Settings` → `Pages` |
| 게시 방식 | `Source` → `Deploy from a branch` |
| 브랜치 | `main` |
| 폴더 | `/(root)` |
| 확정 | `Save` |

게시가 끝나면 같은 페이지스 설정 화면에 표시되는 사이트 방문 버튼으로 게임을 엽니다. **이때 표시되는 주소가 실제 공유할 게임 링크입니다.** 첫 게시나 변경 사항 반영에는 최대 약 10분이 걸릴 수 있습니다.

공식 설명: [페이지스 게시 위치 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [게시된 사이트 확인](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site#viewing-your-published-site)

## 4. 게시 후 확인할 내용

- 닉네임 입력 → 시작 안내 → 게임 시작으로 진행되는지 확인합니다.
- 게임이 휴대폰과 컴퓨터 브라우저에서 열리는지 확인합니다. 3D 그래픽 가속과 웹지엘 2 지원이 필요합니다.
- 작은 화살표가 있는 지름길 입구로 천천히 이동해 통과해도 진입하는지 확인합니다. 세 입구 방향은 왼쪽 → 오른쪽 → 왼쪽입니다.
- 골인 후 유령들의 파티가 나오고, ‘스코어 카드 보러 가기’를 누르면 결과 카드로 이동하는지 확인합니다.
- 수정 전 화면이 남아 있으면 페이지를 새로 열어 확인합니다.

## 포함된 마지막 수정 사항

- 지름길에서 급조향과 방향키 두 번 누르기 조건 제거. 입구를 통과하는 위치만으로 진입합니다.
- 커브를 완만하게 연결하고 카메라 수평·거리·시야각을 유지합니다. 기체의 과한 기울기를 줄였습니다.
- 가까운 건물 벽이 기체를 가리면 잠시 반투명하게 표시합니다.
- 게임 문구의 맞춤법과 띄어쓰기를 교정했습니다.
- 휴대폰 하단 아이템 버튼, 충돌 후 0.5초 감속, 한 개 아이템 보관, 골인 후 DJ 파티와 결과 카드를 포함합니다.

## 다음에 수정할 때

새 수정본의 `index.html`로 이 저장소의 같은 파일을 교체하고 `main`에 반영하면, 설정한 페이지스 주소에 수정본이 게시됩니다. 현재 챗지피티 사이트와 깃허브는 서로 독립적으로 게시되므로 한쪽을 수정해도 다른 쪽에 자동 반영되지는 않습니다.
